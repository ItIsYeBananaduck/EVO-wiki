# Invisible Compute Orchestration

## Concept
Hive bidding and Swarm parallelism must not require user awareness.

## Rule / Mechanism
When delegation or Swarm is used:
- the system proceeds automatically
- the user sees only the final result
- optional subtle indicators may exist, but are off by default

## Why It Exists
Users care about outcomes, not orchestration.

## Implications
- No noisy status UI
- No device selection prompts in normal mode
- Optional diagnostics exist for power users only
