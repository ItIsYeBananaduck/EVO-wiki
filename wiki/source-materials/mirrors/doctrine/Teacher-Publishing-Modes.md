# Teacher-Publishing-Modes
Teacher Publishing Modes
Mode A: Unit Publish
Teacher publishes a full unit (multiple lessons). Students receive all packs immediately. Unlocking is progress/time bounded.
Mode B: Rolling Publish
Teacher publishes lessons as they create them. Students receive packs when available. Daily Pack Preload caches whatever is published + unlocked.
Teacher Override
Teacher can: - push emergency updates - retract a lesson - issue a revised pack version
