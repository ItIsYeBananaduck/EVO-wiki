## Purpose
Standardized structure for sending tasks to stronger reasoning systems.

---

## Structure

### Core Task
- Objective  
- Expected output format  
- Constraints  

### Context
- Relevant logs  
- Prior attempts  
- Environment state  

### External Signals
- Coderabbit comments  
- Greptile analysis  
- Tool outputs  

### Failure Summary
- What failed  
- Why it likely failed  
- What has already been tried  

### Boundaries
- Allowed actions  
- Disallowed actions  
- Scope limits  

---

## Principles

- Minimal but sufficient context  
- No unnecessary data leakage  
- Structured and consistent format  
- Optimized for reasoning clarity
