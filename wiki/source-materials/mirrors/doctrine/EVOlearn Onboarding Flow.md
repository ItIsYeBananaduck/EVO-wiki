# EVOlearn Onboarding Flow
Purpose:

Defines how learners enter EVOlearn.

Steps:

- collect learning goals
- identify current level
- capture preferred learning style where relevant
- set initial pacing expectations

Principle:

Onboarding should be simple, personalized, and low-friction.
