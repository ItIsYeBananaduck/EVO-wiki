# Trainer Plan Delivery and Client Application Doctrine

## Core Principle

Trainer-authored plans are not assigned through centralized runtime mutation.

Trainer plans are delivered through encrypted trainer↔client communication as structured update packages.

The trainer retains the authoritative trainer-side authored/versioned plan.

The client receives a client-side applied copy that becomes part of the client’s local training runtime.

The server must not become the canonical authority for runtime plan ownership, application state, or weekly adaptation state unless future doctrine explicitly changes this model.
