# Talent Execution Path

## Concept
Tasks using a Talent may execute without per-task method approval.

## Rule / Mechanism
If a task references a Talent:
- The Delegator may grant tool access automatically
- Execution is limited to the Talent’s defined scope
- No method mutation is allowed during execution

## Why It Exists
Talents enable safe automation without repetitive approval.

## Implications
- Faster task execution
- Predictable behavior
- User trust is preserved
