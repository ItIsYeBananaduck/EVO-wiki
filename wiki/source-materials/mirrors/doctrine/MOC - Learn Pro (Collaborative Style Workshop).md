# MOC - Learn Pro (Collaborative Style Workshop)

Learn Pro allows collaborative shaping of Alice’s domain styles.

It is:
- Deliberate
- Versioned
- Reversible
- Domain-scoped

It is NOT:
- Unlimited stacking
- Silent adaptation
- Autonomous mutation
