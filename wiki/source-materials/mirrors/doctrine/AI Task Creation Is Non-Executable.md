# AI Task Creation Is Non-Executable
[AI Task Creation Is Non-Executable](https://www.notion.so/33ec72bad01381b9bd50d10e1484f61b)
Concept
Alice may create tasks, but task creation does not imply authorization or execution.
Rule / Mechanism
Tasks created by Alice enter a non-actionable state (e.g., Planned/AwaitingApproval). They cannot execute until: - the method is approved, or - the method is a valid Talent
Why It Exists
Allows autonomy in planning without autonomy in execution.
Implications
Users can review and approve proposed work
Prevents silent automation
Aligns with method/talent gating
