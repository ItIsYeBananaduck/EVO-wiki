# Talent Trainer Overview

## Concept
Talent Trainer enables users to teach Alice a repeatable action by demonstration.

## Rule / Mechanism
The user performs the action while the app records the screen.
Alice analyzes the recording to produce a method proposal, including required tools and user inputs.
The user and Alice run through the task together for verification.
Upon user approval, the method becomes a Talent.

## Why It Exists
Eliminates the need for a skills marketplace while preserving safety and user ownership.

## Implications
- Talents can be user-created without third parties
- Safety is demonstrated, not assumed
- Trust is explicit
