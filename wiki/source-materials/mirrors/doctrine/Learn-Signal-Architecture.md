# EVOlearn Signal Architecture

## Learn Signals (Examples)
- engagement trend (session length, drop-off points)
- comprehension confidence (low/med/high)
- retention signal (review success, spacing needs)
- frustration signal (self-report + behavioral cues)
- preferred modality (visual, practice, stories, games)

## Ecosystem Integration Rule
Learn signals can influence:
- when to teach
- what to review
- how to present material

Learn signals must NOT:
- become fitness or mind diagnoses
- infer sensitive personal traits
- be shared socially by default
