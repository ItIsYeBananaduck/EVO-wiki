## Core Idea

Connect is:

OpenClaw-style agent execution, redesigned to be safe, observable, and usable by everyone — not just technical users.

It enables Alice to perform real-world actions (local, web, and tool-based) inside a controlled system that prioritizes:
- safety
- visibility
- governance
- usability

---

## Problem Statement

Current agent systems (like OpenClaw-style tools) are powerful but assume:

- technical users
- comfort with risk
- low visibility into actions
- direct access to sensitive capabilities
- loosely governed execution

This creates friction for:
- non-technical users
- safety-conscious users
- real-world use cases involving sensitive data

---

## Solution

Connect introduces:

Controlled Agent Execution

Instead of giving Alice raw power, Connect provides:

- bounded capabilities
- observable actions
- governed execution
- interruptible workflows
- domain-aware behavior

Alice can still act — but within a system designed for trust.

---

## Key Principles

### 1. Controlled Surfaces
Alice operates through:
- EVOterminal (local execution)
- Lightweight browser (web execution)

These are:
- minimal
- fast
- purpose-built for Alice
- not full user applications

---

### 2. User as Supervisor (Not Operator)

The user:
- observes Alice’s actions
- intervenes when needed
- teaches or corrects workflows
- approves sensitive actions

The user is not required to:
- use a terminal
- manage tools
- understand technical workflows

---

### 3. Governance First

All actions pass through:
- Delegator (permissions + approvals)

Alice:
- does not act freely
- uses approved capabilities
- respects boundaries

---

### 4. Vault-Based Security

Sensitive data is handled through a protected vault:

- passwords
- identity fields
- tokens
- personal information

Alice:
- does not access raw secrets by default
- requests capabilities instead
- uses values without exposing them

---

### 5. Talents Over Raw Tools

Alice does not use tools directly.

She uses:
Talents (reusable, governed skills)

Talents:
- define structured workflows
- combine tools safely
- produce predictable outcomes

---

### 6. Domain-Aware Behavior

Connect adapts to context through DomainBinding:

- Training
- Connect (development)
- Mind
- Learn

Each domain:
- exposes different Talents
- enables different tools
- enforces different rules

---

### 7. Hive-Based Execution

Execution is routed intelligently:

- local device
- desktop
- other nodes

Hive determines:
- where actions run
- based on capability requirements

---

## What Connect Is Not

Connect is NOT:

- a full browser
- a full terminal
- a raw automation engine
- a developer-only tool
- a black-box AI system

---

## What Connect Is

Connect is:

A controlled workspace where Alice can safely perform real-world actions on behalf of the user.
