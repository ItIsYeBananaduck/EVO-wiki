# Escalation - Multi Concept Priority Logic
[Escalation – Multi Concept Priority Logic](https://www.notion.so/33ec72bad013817aa3bfced43cb39464)
Escalation priority increases when stall spans multiple related concepts.

Priority Rules
Within same unit or concept cluster:
1 stalled concept → Low 2 stalled concepts → Medium 3+ stalled concepts → High

Relatedness Determination
Concepts considered related if: - same unit_id - same prerequisite chain - teacher-defined cluster - template-tag overlap

Rationale
Multi-concept stall often indicates: - foundational misunderstanding - prerequisite gap - cognitive overload
Priority increase affects: - teacher notification urgency - dashboard highlighting
Consent is still required.
