# Learn Pro - Workshop Flow

- Structured extraction
- User selects what to learn

Step 2 – Conflict Mapping
- Identify contradictions

- Allow override

Step 3 – Scope Placement
- Define where style applies
- Define activation rules

Step 4 – Preview
- Before/After examples
- What changes
- What stays

Step 5 – Apply
- Create new snapshot
- Archive previous
