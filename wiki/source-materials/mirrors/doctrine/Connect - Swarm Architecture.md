# Connect - Swarm Architecture

Swarm = distributed compute engine.

Purpose:
Increase performance without sacrificing efficiency.

Features:
- Micro-task splitting
- Parallel inference
- Capability-aware distribution
- Timeout-based fallback
- Battery-aware execution

Swarm is:
- Temporary
- Performance-based
- Non-agentic unless Pro delegation is active

If a node drops:
- Work is redistributed
- No crash cascade
