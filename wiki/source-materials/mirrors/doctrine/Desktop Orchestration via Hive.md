## Purpose
Enable Alice to use the most capable device in the Hive for environment-based tasks.

---

## Core Idea

Not all devices are equal.

Hive allows:
- routing tasks to capable nodes  
- executing where the environment exists  
- maintaining a single shared consciousness  

---

## Example Flow

1. Escalation triggered on mobile  
2. Hive detects desktop node availability  
3. Desktop becomes active execution node  
4. EVOterminal runs task  
5. Result returns to shared task system  

---

## Responsibilities

Hive handles:
- node discovery  
- capability detection  
- execution routing  
- leader assignment  

---

## Rules

- One active execution node  
- Nodes can join/leave safely  
- No user-visible node chatter  
- Seamless experience  

---

## Benefits

- Use desktop for heavy tasks  
- Keep mobile lightweight  
- Maintain unified experience  
- Enable real-world workflows  

---

## Relationship to Swarm

- Hive = coordination  
- Swarm = compute  

Environment orchestration is Hive-driven.
