# Connect - Free vs Pro Architecture

## Free Tier

- App hub for all EVO apps
- Alice chat
- Swarm (performance boost only)
- Node visibility
- Task summary (read-only)

No:
- Autonomous delegation
- Tool execution
- Terminal control
- Talent execution

---

## Pro Tier

Full Connect experience:

- Delegated tasks
- Hive orchestration
- Internal browser (Talent training)
- Internal terminal sandbox
- Tool access (bounded)
- Cross-device task execution
- Mesh-level intelligence routing
