# Learn – Eureka Mechanic

During micro-lesson:

If student understands early:
Eureka button becomes available.

Student must:
Provide correct answer independently.

If correct:
Answer is NOT purple.

Eureka encourages:
Agency
Confidence
Self-recognition of comprehension
