# Method Reuse Requires Re-Approval

## Concept
Reusing an approved method still requires user approval unless it has been promoted to a Talent.

## Rule / Mechanism
If a task references an approved method (not a Talent):
- Alice presents the method proposal again
- The user must approve again
- Only then does the Delegator grant scoped tool access

## Why It Exists
Repeated consent prevents “silent automation” and ensures the method is still appropriate.

## Implications
- Approved methods accelerate planning, not authorization
- Users can decline reuse at any time
