Learn – Self-Study Mode (Ingestion Notebook)

Self-Study Mode is the core non-institution learning experience.

It behaves like a smart notebook / ingestion platform:
- user adds material (PDF, scans, notes, transcriptions, homework photos)
- SA builds a local source map
- SA teaches using approved Templates via Talents
- Strict Mode applies (verification-first)

Self-Study Mode is shared by:
- Adults
- Kids (outside school mode)

Differences are controlled by Policy Profiles:
- Adult Profile: broad topic freedom
- Kids Profile: restricted topics + optional guardian management
