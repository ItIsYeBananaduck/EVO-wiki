# EVO Book - Manuscript Map
## Purpose

Create a canonical manuscript map for a future EVO doctrine / architecture book.

This note exists to:

- gather the strongest doctrine notes into a coherent structure
- identify chapter-level themes
- provide a consolidation target for tiny or overlapping notes later
- preserve the difference between canonical notes and manuscript-ready chapter groupings

---

## Core Thesis

EVO is not a generic AI system.

It is a trust-first, local-first, governed intelligence architecture built around:

- user sovereignty
- bounded execution
- preserved capability
- visible governance
- AI as extension, not replacement

---

## Book Direction

This is not a generic AI book.

It is a doctrine and architecture book about building personal AI systems that remain:

- useful
- governed
- aligned
- privacy-preserving
- structurally auditable

---

## Consolidation Use

This manuscript map should also act as a cleanup target.

When a note is too small to justify standing alone, it should be evaluated as one of:

- a section to append into a stronger canonical note
- a subsection to attach to a future manuscript chapter
- a deprecated fragment to archive

---

## Keep / Append / Archive Framework

### Keep Standalone

Use for notes that:

- define a unique rule
- act as a canonical anchor
- are heavily linked
- should be cited independently

### Append Into Parent

Use for notes that:

- are very small
- mostly refine a stronger note
- duplicate an existing doctrine section
- function better as a subsection than a top-level note

### Archive

Use for notes that:

- are superseded
- are transitional
- duplicate newer doctrine
- no longer add independent value

---

## Final Principle

The goal is not to force the notes into a book.

The goal is to make the doctrine coherent enough that a book becomes a natural byproduct of the system.
