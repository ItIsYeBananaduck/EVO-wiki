# Adaptive Variable Adjustment

## Concept
Adaptation occurs by adjusting only one primary variable at a time.

## Rule / Mechanism
The system adjusts one of:
- Sets
- Reps
- Load

Never more than one per adaptation cycle.

## Why It Exists
Changing multiple variables simultaneously obscures cause and effect.

## Implications
- Clear signal attribution
- Predictable progression
- Easier rollback if needed
