# Primary Variable Selection
[Primary Variable Selection](https://www.notion.so/33ec72bad01381e2ba06c3b901906d6d)
Concept
At any adaptation point, the system must choose a single primary variable to adjust.
Rule / Mechanism
Only one of the following may be selected: - Load - Reps - Sets
Selection is based on signal clarity and risk.
Why It Exists
Simultaneous changes obscure causality and increase injury risk.
Implications
Adaptation is interpretable
Rollbacks are simple
Users trust changes more
