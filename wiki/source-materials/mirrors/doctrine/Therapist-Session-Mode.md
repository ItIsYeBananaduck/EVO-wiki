# Therapist Session Mode

## Purpose
Use conversation awareness signals to support therapist-led coping experiments.

## Roles
Therapist:
- leads session
- selects techniques
- interprets outcomes
- writes notes

Alice:
- provides real-time awareness signals (stress gauge / trend)
- does NOT diagnose
- does NOT interpret relational toxicity
- does NOT write therapy notes
- does NOT provide “official” psychological advice
