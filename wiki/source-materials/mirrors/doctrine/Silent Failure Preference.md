# Silent Failure Preference
[Silent Failure Preference](https://www.notion.so/33ec72bad01381f08788c4aa9792b76f)
Concept
When inference is unavailable or constrained, the system should degrade gracefully without noisy errors.
Rule / Mechanism
If Alice cannot run: - produce a basic deterministic output - queue enhanced output for later if valuable - avoid interrupting the user unless safety-critical
Why It Exists
Failure modes should preserve trust and flow.
Implications
No broken-feeling UI
Deferred intelligence is normal
Users remain in control
