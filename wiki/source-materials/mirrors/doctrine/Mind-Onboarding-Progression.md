# EVOmind Onboarding Progression

Week 1:
- Random mood check-ins (emoji picker)
- Cross-reference wearable data if available

Week 2:
- Same check-ins
- Add context: location category
- Add stress category for stressful moods

Week 3:
- Begin prediction attempts (health data pings if wearable)
- Unlock conversational journaling

Unlock condition:
- As prediction accuracy becomes consistent, unlock Conversation Awareness mode.
