# Teacher Template Sharing Platform

## Purpose
Allow teachers to share structured method templates that improve lesson packaging and student retention.

## Template Contents
- method structure (sequence of steps)
- prompt scripts / teacher phrasing examples
- pacing guidance
- misconceptions to target
- allowed adaptations for Student Alice
- grade band + subject tags
- "best used when" notes

## Teacher Alice Use
- TA can recommend templates.
- Teacher must approve any template adoption.
- Adoption modifies MethodProfile / TL only after explicit approval.

## Student Alice Use
- Student can experiment with methods only within teacher-defined allowed_adaptations.
- Student-facing descriptions must be neutral and respectful of teacher authority.

## Safety
- No student data included.
- No teacher private notes included.
- Templates are moderated / vetted (community + policy).
