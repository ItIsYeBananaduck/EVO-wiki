# On-Device First Principle
[On-Device First Principle](https://www.notion.so/33ec72bad0138100bbe3ebc5c290f7b8)
Concept
All inference should occur on-device whenever possible.
Rule / Mechanism
Local inference is the default. Remote inference is used only when capability gaps exist.
Why It Exists
Privacy, latency, reliability, and trust all improve when intelligence stays local.
Implications
No dependency on network availability
User data remains private
AI feels immediate and responsive
