## Core Principle

> Tasks are the supervision layer for all agent execution.

---

## Role

Tasks provide:

- visibility  
- approval surface  
- correction surface  
- execution tracking  
- learning signals  

---

## Supervision Levels

- full approval (Methods)  
- partial approval  
- post-hoc review (external agents)  

---

## Learning Signal

User feedback determines:

- success  
- failure  
- inconclusive  

---

## Law

> Correction is a learning signal, not just feedback.

---

## Group Chat Role

Group chat allows Alice to observe:

- agent reasoning  
- user corrections  
- intent clarification  

---

## Key Advantage

Alice learns:

- what the user meant  
- not just what the user said
