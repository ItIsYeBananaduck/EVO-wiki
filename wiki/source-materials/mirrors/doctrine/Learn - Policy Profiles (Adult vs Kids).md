# Learn - Policy Profiles (Adult vs Kids)
[Learn – Policy Profiles (Adult vs Kids)](https://www.notion.so/33ec72bad013810fb9e6c5de2f0e9531)
Policy Profiles configure: - Allowed topic scope - Required supervision features - Content filtering behavior - Logging / visibility expectations
They do NOT change SA core logic. They constrain access and presentation.

Adult Profile
Broad learning scope
Minimal restrictions (legal compliance only)
Self-managed ingestion
Optional tutor link
No institutional reporting

Kids Profile (Self-Study)
Restricted topic scope
Age-tiered supervision (optional/required by age)
Self-study behaves like adult mode, but filtered
Guardian can manage:
allowed subjects
time windows
ingestion sources
export/sharing permissions
No school reporting unless School Mode is enabled.
