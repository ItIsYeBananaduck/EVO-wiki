#connect
## Purpose
Define how Alice uses stronger models or tools as temporary specialists.

---

## Model Roles

- Deep reasoning (architecture, synthesis)  
- Code correction  
- Conflict resolution  
- Long-context analysis  

---

## Behavior

- External systems are not trusted blindly  
- Results must be evaluated before acceptance  
- Multiple sources may be queried for comparison  
- Output must fit required structure  

---

## Constraints

- No direct execution from external outputs  
- Must pass through Delegator  
- Must be logged and auditable
