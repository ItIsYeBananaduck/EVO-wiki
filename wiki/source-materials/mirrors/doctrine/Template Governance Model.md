# Template Governance Model
Learn – Template Governance Model
Templates are globally available but moderated.
Rules:
Private by default
Promotion requires threshold + review
No infinite micro-forks
Significant change required for new template approval
Lineage tracking required. Duplicate detection required.
Goal: Prevent 1000 minor variations. Encourage meaningful method diversity.
