## Core Principle

> The user defines what is worth learning.  
> Alice transforms it into structured learning and improves over time.

This system enables:

- fully personalized AI behavior  
- domain-specific capability growth  
- user-controlled training data  
- private, on-device learning  

---

## 🧠 System Goal

> Create a personal AI that improves based on **user-selected information**, not external scraping.

This avoids:

- unwanted bias from external sources  
- irrelevant knowledge  
- loss of user control  

---

## 🧩 What is an Adapter

An Adapter is:

> A domain-specific capability shaped by curated examples and learned patterns

Examples:

- coding style adapter  
- task management adapter  
- communication style adapter  
- fitness coaching adapter  
- business workflow adapter
