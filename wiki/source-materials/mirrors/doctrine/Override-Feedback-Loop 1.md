# Override Feedback Loop

## Principle
Alice advises; user decides.

## When user overrides
1. Log divergence (what changed vs recommendation)
2. Observe outcomes (fatigue trend, performance trajectory)
3. Update personal calibration if repeated overrides succeed safely
4. Surface gentle trend warnings if recovery takes a hit

## Tone for warnings
Calm, non-judgmental:
“I’ve noticed recovery time increasing over the last few weeks. This can lead to plateau or regression.”
