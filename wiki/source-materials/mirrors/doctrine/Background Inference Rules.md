# Background Inference Rules
[Background Inference Rules](https://www.notion.so/33ec72bad01381e4861ae0e04fc67d34)
Concept
Alice must be able to think without demanding user attention.
Rule / Mechanism
Background inference is permitted only for: - State updates - Trend aggregation - Preparation for future actions
No user-facing output is produced in the background.
Why It Exists
Background execution should prepare intelligence, not perform interaction.
Implications
Smooth foreground experience
Lower perceived latency
Reduced interruptions
