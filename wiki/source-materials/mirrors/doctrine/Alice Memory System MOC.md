# Alice Memory System MOC
## Purpose

This document serves as the navigation and structure map for Alice’s memory system across EVO.

Alice’s memory system is built around a visible journal, internal separation between user and work knowledge, a daily reflection loop, and a staged path from memory into adapter updates.

Memory comes before compression.

Alice first learns visibly and source-backed through journals.
