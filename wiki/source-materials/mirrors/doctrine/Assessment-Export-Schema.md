# Teacher Assessment Export Schema (Sanitized)

Export elements (examples):
- topic_tag: "fractions"
- mastery: low|med|high
- evidence_window: last_5|last_10
- classroom_observation: optional short note (curriculum-only)
- recommended_practice: "more worked examples" | "more independent practice" | "spaced review"
- confidence: low|med|high

No freeform sensitive notes.
No psychological interpretation.
