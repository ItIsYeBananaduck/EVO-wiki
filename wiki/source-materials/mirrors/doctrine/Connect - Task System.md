# Connect - Task System

Two categories:

## My Tasks
- Personal reminders
- Manual tasks
- No AI execution

## Alice Tasks
- Delegated
- Governed by Delegator
- Must bind to a Method or Talent
- Logged

Task lifecycle:
Created → Reviewed → Approved → Executed → Logged → Completed

Connect shows:
- My task count
- Alice task count
- Node status
