# Co-Piloted Verification Run

## Concept
Talent Trainer requires a supervised execution before a Talent is created.

## Rule / Mechanism
Before promotion, Alice must execute the proposed method with the user observing and able to intervene.
Tool access remains scoped and bounded during verification.

## Why It Exists
Demonstration reduces risk and gives the user direct confidence.

## Implications
- Users see exactly what will happen
- The method is validated in practice, not theory
