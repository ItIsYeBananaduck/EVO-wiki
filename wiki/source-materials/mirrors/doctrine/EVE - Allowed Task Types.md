# EVE – Allowed Task Types

EVE tasks are strictly analytics-only.

Allowed:
- compute metric
- aggregate cohort stats
- compare distributions
- detect drift/anomalies
- generate report artifacts
- export report locally (PDF/CSV)
- write to local dashboard store

Not allowed:
- contacting users
- changing business systems
- triggering operational actions
- modifying assignments
- sending messages
- performing web automation

EVE outputs insights only.
Humans decide actions.
