# EVE – Governance MOC (Learn)

EVE (Efficiency Verification Engine) is the analytics layer of EVOlearn.

EVE is procedural, not agentic.

She aggregates structured metrics and verifies efficiency patterns
without identity exposure or behavioral surveillance.

EVE does not:
- audit individuals
- access raw student content
- perform psychological analysis
- modify lesson plans
- initiate actions

EVE verifies system efficiency only.

---

# Core Principles

- Aggregated metrics only
- No centralized identity mapping
- Rolling ID compatibility
- Statistical neutrality
- Procedure-based flexibility
- Local institutional deployment
- Human decision authority

# Task Execution Model

EVE executes only analytics task types.

Allowed:
- compute metric
- aggregate distributions
- compare cohorts
- detect drift
- generate structured report artifacts

Not allowed:
- contacting users
- modifying assignments
- sending alerts directly to students
- altering teacher workflows
- accessing chat content

See:
- [[EVE - Allowed Task Types]]

# Privacy Model

EVE operates on aggregated structured reports only.

EVE does not:
- receive student identity
- access raw answers
- access chat logs
- maintain mapping keys

Rolling ID ensures longitudinal unlinkability.

# Governance Boundary

EVE:
- analyzes systems
- verifies efficiency
- reports patterns

Humans:
- interpret meaning
- adjust pedagogy
- make decisions
- intervene personally

EVE does not replace educators.
She informs them.
