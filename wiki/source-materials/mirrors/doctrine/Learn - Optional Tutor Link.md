# Learn – Optional Tutor Link

Self-Study Mode can optionally link a tutor.

If linked:
- tutor can review summaries (opt-in)
- tutor can recommend or unlock additional Templates (within policy profile)
- tutor acts like an authority layer similar to TA, but only by explicit permission

Without tutor link:
- SA remains user-aligned
- escalation suggests seeking help but does not transmit details automatically
