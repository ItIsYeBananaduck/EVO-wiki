# Learn Pro — User Curation Workshop

## Purpose
Learn Pro is the user-curated learning workshop for EVO. It translates domain documents into teachable lesson packs.

## Workshop Flow
- Source selection
- Concept extraction
- Style matching
- Validation before promotion

## Domain Styles
Styles are bounded system profiles. A style defines pacing, example density, scaffolding depth, and tutor link behavior.

## Mesh Integration
Learn Pro integrates EVE mesh scheduling so curated lesson packs can be attached to adaptive training windows without collapsing into generic content.
