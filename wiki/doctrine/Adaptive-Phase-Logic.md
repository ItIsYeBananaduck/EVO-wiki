# Adaptive Phase Logic
An Adaptive Phase Milestone is triggered at mesocycle completion when:
Required Signals: - Positive or stabilized performance trajectory - No unmanaged recovery drift - Fatigue trend within safe threshold - Nutritional alignment within tolerance band - Deload adherence (if applicable)
Tolerance Rule: - Minor macro deviations allowed - Short-term performance dips allowed - Trend-based evaluation > single-session evaluation
Milestones reflect system coherence, not perfection.
