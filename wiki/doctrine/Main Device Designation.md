# Main Device Designation
[Main Device Designation](https://www.notion.so/33ec72bad01381dfa1e9cafa22fc7ce4)
Concept
A user must have a designated main device for the Hive.
Rule / Mechanism
The first paired device becomes the default main device
The user may transfer “main device” status explicitly
Main device status transfer requires confirmation and revokes pairing authority from the previous main device
Why It Exists
Pairing authority must be unambiguous.
Implications
Clear control plane
Safe upgrades/replacements when users change phones
