# District Envelope + Philosophy Tags
Learn – District Envelope + Philosophy Tags
Each school defines an envelope.
Envelope includes: - Approved learning philosophies - Disallowed methodologies - Testing structure constraints
Templates are tagged with philosophy categories.
Selection Mesh respects envelope strictly.
If a student benefits from a disallowed philosophy: Teacher must manually unlock alternative.
