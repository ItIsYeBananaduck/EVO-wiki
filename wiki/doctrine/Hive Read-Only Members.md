# Hive Read-Only Members
[Hive Read-Only Members](https://www.notion.so/33ec72bad01381858f33f86faac12d1f)
Concept
Hive members without the execution lease operate in read-only mode.
Rule / Mechanism
Read-only Hive members may: - display chat - display tasks - propose tasks or methods - plan and reason
They may not: - execute tasks - access tools - resolve secrets
Why It Exists
Keeps all devices useful while preserving safety.
Implications
Tablet can observe while phone executes
Laptop can plan while phone runs a task
