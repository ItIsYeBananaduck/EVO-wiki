# EVOconnect Browser & Terminal Execution Model
Purpose:

Defines execution rules for browser and terminal surfaces.

Core Principle:

Different execution surfaces require different trust envelopes, approval rules, and operational constraints.

Model:

- browser execution for web interaction and connector-like operations
- terminal execution for more direct system-level action
- selection depends on task needs, permissions, and governance bounds

Relationship:

Connected to Execution Model, Privileged Execution Model, Plugin Model, and surface selection logic.

Final Principle:

The execution surface is part of the governance model, not just a technical detail.
