# Non-Intrusive Guidance
[Non-Intrusive Guidance](https://www.notion.so/33ec72bad013810e9792e13c03de6618)
Concept
Guidance should never interrupt user flow unless safety is involved.
Rule / Mechanism
Alice does not interrupt workouts, focus sessions, or learning unless: - Risk is detected - User explicitly asks - A phase boundary is reached
Why It Exists
Interruptions degrade trust and performance.
Implications
Alice feels considerate
Users stay in flow
Interventions feel justified
