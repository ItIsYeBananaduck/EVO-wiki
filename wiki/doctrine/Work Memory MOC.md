# Work Memory MOC
## Purpose

This document serves as the navigation map for work-specific memory governed by Connect.

Work memory captures what Alice learns about workflows, execution, agent behavior, and reasoning mistakes so she can improve how she works over time.

## Core Questions

- What counts as a reusable execution lesson?
- What should be learned from observing agents and workflows?

## Principle

Work memory is how Alice learns how to help and execute better, not who the user is.
