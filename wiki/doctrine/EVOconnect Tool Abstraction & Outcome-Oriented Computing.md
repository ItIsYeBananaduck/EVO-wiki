# EVOconnect Tool Abstraction & Outcome-Oriented Computing
Purpose:

Defines the abstraction layer between desired outcomes and raw tools.

Core Principle:

Users and agents should think in outcomes first. Tools are selected and governed behind that layer.

Implications:

- raw tools are abstracted
- execution focuses on desired outcome
- tool choice remains bounded by Delegator and permissions
- orchestration becomes more stable and portable across environments

Relationship:

Connected to Plugin Model, Execution Model, and workspace/task orchestration.

Final Principle:

The system should optimize for outcomes, not expose unnecessary implementation detail.
