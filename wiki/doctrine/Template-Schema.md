# Template-Schema
Learning Template Schema
Purpose
Reusable learning method module. Does not contain curriculum content.
Required Fields
template_id
name
description
method_steps (ordered list)
recommended_use_cases (tags)
grade_band
subject_tags
allowed_in_kids_mode (bool)
compatible_content_types (explain|practice|assessment|review)
cognitive_target (e.g., retention|conceptual|procedural)
Optional
pacing_profile (micro|standard|deep)
difficulty_adjustment_rules
hint_strategy
feedback_style
“when_not_to_use”
sample_prompt_examples (human-readable)
Philosophy_tags: - Direct Instruction - Inquiry-Based
District_compliance_flags: - allowed - restricted - review_required
Method_signature: - cognitive_target: conceptual - scaffolding_level: high - retrieval_intensity: medium - structure_type: guided_release
