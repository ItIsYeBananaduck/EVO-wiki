# EVO — Cognition Layer

> NOTE: This is a canonical doctrine note.
> All updates must preserve structure.
> Do not introduce conflicting definitions.

---

## Purpose
Define how Alice perceives, organizes, and reasons about information across all EVO applications.

The cognition layer connects:
- raw signals
- interpreted meaning
- confirmed truth
- learned behavior

---

## Core Principle
Cognition is layered and governed.

Each layer has a distinct role and must not be conflated.

---

## Definitions

**Logs**  
Objective records of user actions, system events, and outcomes.

**Observations**  
Unvalidated insights derived from logs or interactions.

**Journal Entries**  
Alice’s interpretation of logs and observations.

**Living Notes**  
User-confirmed knowledge representing truth.

**Scratch**  
Temporary workspace for unresolved or evolving ideas.

**Adapters**  
Personalized learning layers trained on validated patterns.

---

## System Structure

The cognition layer consists of five components:

1. Evidence Layer → Logs  
2. Insight Layer → Observations  
3. Meaning Layer → Journal Entries  
4. Truth Layer → Living Notes  
5. Learning Layer → Adapters  

---

## Rules

- Logs are immutable  
- Observations are provisional  
- Journals must allow correction  
- Living Notes require approval  
- Adapters require validated patterns  

- Journals must not become truth without approval  
- Living Notes must not auto-update  
- Adapters must not train on unvalidated data  

---

## Flow

Logs → Observations → Journal Entries → Living Notes → Adapters  

Each transition increases validation.

## Edge Cases / Special Handling

**Conflicts**
- Resolved only at Living Notes layer

**Scratch**
- Used for unresolved or evolving ideas  
- Not truth  
- Not training data  

**Cross-domain cognition**
- Unified when Connect is active  
- Separate when Connect is inactive  

---

## Summary

The cognition layer defines how Alice:

- observes reality (logs)  
- interprets meaning (journals)  
- confirms truth (living notes)  
- learns behavior (adapters)  

It ensures:
- separation of concerns  
- controlled learning  
- safe adaptation
