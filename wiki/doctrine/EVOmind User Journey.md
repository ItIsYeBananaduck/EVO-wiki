# EVOmind User Journey
## Purpose

Define the user experience progression within EVOmind, from onboarding through deeper interaction modes.

---

## Core Concept

EVOmind is not a single interaction mode.

It is a progression from light engagement to deeper reflective states.

---

## Onboarding Progression

Early experience should:

- feel simple and low-pressure
- establish trust
- introduce conversational journaling
- avoid overwhelming the user

The goal is gradual familiarity, not immediate depth.

- Week 1: - Random mood check-ins (emoji picker) - Cross-reference wearable data if available
- Week 2: - Same check-ins - Add context: location category - Add stress category for stressful moods
- Week 3: - Begin prediction attempts (health data pings if wearable) - Unlock conversational journaling
Unlock condition: - As prediction accuracy becomes consistent, unlock Conversation Awareness mode.

---

## Mid-Stage Interaction

As familiarity increases:

- conversations become more reflective
- context awareness improves
- the system begins guiding patterns

---

## Therapist Session Mode

This mode should:

- feel safe and contained
- avoid feeling clinical or rigid
- maintain the identity of Alice

### Therapist Session Mode Explained

Use conversation awareness signals to support therapist-led coping experiments.

- Therapist: - leads session - selects techniques - interprets outcomes - writes notes
- Alice: - provides real-time awareness signals (stress gauge / trend) - does NOT diagnose - does NOT interpret relational toxicity - does NOT write therapy notes - does NOT provide “official” psychological advice

---

## Progression Model

User experience evolves based on:

- usage patterns
- comfort level
- emotional engagement

The system should adapt without forcing progression.

---

## Awareness Unlock Model

Conversation Awareness should not be immediately active.

It should unlock progressively based on:

- prediction accuracy stability
- sufficient interaction history
- user comfort signals

This ensures:

- the system does not overstep early
- awareness feels earned, not intrusive

---

## Final Principle

EVOmind is a journey, not a feature.

The system should meet the user where they are and evolve with them.
