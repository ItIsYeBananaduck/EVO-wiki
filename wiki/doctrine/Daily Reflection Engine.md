# Daily Reflection Engine
## Purpose

Define the once-daily reflection process that turns logs into durable journal memory.

## Frequency

- once per day

## Input Sources

- Training logs
- Mind logs and journal activity
- Learn interaction history
- Connect execution logs

## Process

1. Review the day's logs
2. Identify repeated or meaningful signals
3. Create candidate user and work journal entries
4. Link related entries
5. Present one unified reflection to the user

## Entry Threshold

Alice should only write entries when:

- the pattern repeated
- the signal is meaningful
- the observation appears stable
- a correction occurred
- an execution lesson seems reusable

## User Presentation

The user sees one daily reflection containing:

- what I learned about you
- what I learned about helping you better

Internally, Alice still writes to two journals.

## Notification Rule

One notification per day:

“Alice has a reflection for you”

If Connect is installed, open in Connect.

Otherwise, open in the current app context.

## Principle

Reflection is daily, but durable memory should remain selective.
