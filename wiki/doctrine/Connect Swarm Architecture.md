# Connect Swarm Architecture
Purpose:

Defines distributed compute behavior in the Connect ecosystem.

Core Principle:

Hive coordinates. Swarm computes.

Functions:

- execute distributed workloads
- divide or sequence heavier work across nodes
- support scalable compute participation under coordination rules

Rules:

- compute roles are coordinated by Hive
- execution remains bounded and governed
- node participation must remain safe and reversible

Relationship:

Connected to Hive, Runtime Model, and distributed execution flows.

Final Principle:

Distributed power must still obey centralized governance.
