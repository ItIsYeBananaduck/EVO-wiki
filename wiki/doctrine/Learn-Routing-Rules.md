# Learn-Routing-Rules
Learn Routing Rules
Goal
Select the best route per user/session without forcing one universal experience.
Inputs
user intent (what they asked for)
age mode (adult vs kids)
attention profile (short sessions vs deep work)
past engagement + retention patterns
context (time available, device type)
Output
One active route per session: Tutor / Game / Curriculum / Project / Study Companion
Principle
Alice adapts presentation style first. Content second.
