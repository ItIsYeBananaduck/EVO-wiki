# Learn - Kids Restricted Topics
[Learn – Kids Restricted Topics](https://www.notion.so/33ec72bad01381fe96a0dbf126afad6a)
Kids Self-Study Mode is the same as Self-Study Mode, but with topic restrictions.
Restrictions are applied to: - user-ingested material (classification + filtering) - SA responses (safe completion rules) - suggested learning paths
Restrictions are age-tiered: - younger kids: tighter restrictions + stronger guardian controls - older kids/teens: broader access but still filtered
Design goal: Keep learning open, but prevent exposure to inappropriate topics for minors.
