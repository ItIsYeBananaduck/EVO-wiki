# Screen Recording Privacy Boundary
[Screen Recording Privacy Boundary](https://www.notion.so/33ec72bad013816a84dcfd811e4973be)
Concept
Talent Trainer screen recordings must be privacy-safe by design.
Rule / Mechanism
Recordings are: - stored locally (default) - used only to derive the method for the demonstrated task - deletable by the user at any time
No recording is used for unrelated learning.
Why It Exists
Screen recordings can contain highly sensitive information.
Implications
Strong trust foundation
Clear user ownership of training data
