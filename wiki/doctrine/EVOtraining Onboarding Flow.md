# EVOtraining Onboarding Flow
Purpose:

Defines how new users enter EVOtraining.

Steps:

- collect basic metrics (age, weight, height)
- collect activity level
- capture medical considerations
- explain system expectations

Principle:

Onboarding should be simple, fast, and safe.
