# Talent & Template System

## Templates
Templates are method specifications. They define task shapes, execution gates, and approval criteria.
- Template schema defines required fields
- Execution rules apply to all instances of a template
- Templates are prescriptive, not inferred

## Talents
Talents are runtime instances of method capability.
- Promotion requires explicit consent
- Talents are immutable once promoted
- Revocation is explicit and time-bounded

## Approval Path
Method reuse requires re-approval. Promotion thresholds prevent automatic escalation.
