# Hint Retry Ask Alice Flow
Learn – Hint → Retry → Ask Alice
When a student answers incorrectly:
Offer hint
Retry
Ask Alice button appears
Ask Alice requires: - Micro-lesson - Demonstration of understanding - Self-rating of understanding
This ensures: No passive answer consumption. Effort is required.
Unlimited usage allowed. Confusion is not punished.
