# Delegator Tool Hostage Rule
[Delegator Tool Hostage Rule](https://www.notion.so/33ec72bad013817d9b6bcc64f4a096fd)
Concept
The Delegator enforces execution authorization by controlling tool access.
Rule / Mechanism
Until the Task Actionability Gate is satisfied: - No tools are available - No side effects may occur - Execution is impossible
Why It Exists
Tool access is the real power boundary.
Implications
Safety rules are enforceable
Autonomy cannot bypass consent
System behavior is auditable
