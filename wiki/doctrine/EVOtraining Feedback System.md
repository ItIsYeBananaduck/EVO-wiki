# EVOtraining Feedback System
Purpose:

Defines how users provide feedback after each set.

Options:

- easy
- moderate
- hard

Role:

Provides a low-friction signal for adaptation.

Principle:

Simple feedback enables consistent data collection and better long-term adaptation.
