# EVOconnect — Execution Surface Selection & Approval Model

## Purpose
Select browser, terminal, desktop, or mobile execution target based on task type and app contract.

## Approval Model
Execution path requires explicit approval by task category. High-risk browser or terminal execution can not be triggered by web content.
