# EVE Procedure Override Model
Purpose:

Defines how governance can override standard procedures when necessary.

Core Principle:

Overrides must be explicit, bounded, auditable, and rare.

Rules:

- overrides require clear authority
- overrides must be logged
- overrides cannot silently become defaults
- overrides must preserve reviewability

Principle:

An override is an exception layer, not a shortcut.
