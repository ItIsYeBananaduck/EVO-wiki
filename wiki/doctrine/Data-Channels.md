# Data-Channels
Data Channels (Student vs Teacher)
Channel A: Student Private Profile
Owner: Student Visible to: Student Alice only Not visible to: Teacher, Teacher Alice, school staff
Includes: - likes (in/out of school) - pain points with learning (self-report) - perceived strengths - preferred learning style - goals
Channel B: Teacher Assessment Feed
Owner: Teacher Visible to: Teacher + Teacher Alice Shareable to: Student Alice (sanitized)
Includes: - skill mastery signals - curriculum topic strengths/needs - completion + attempt trends - teacher-chosen learning mode notes (optional)
Prohibited: - medical or psychological claims - personality judgments - relational labels - sensitive personal inferences
