# EVE Procedures - Scheduling + Report Requests
[EVE Procedures – Scheduling + Report Requests](https://www.notion.so/33ec72bad01381fa9565d8cb5092307d)
Procedures define:
report frequency (daily/weekly/monthly)
requested scope (which grades/departments)
aggregation grouping (by grade, by school)
output format (summary, deep dive, heatmap)
anomaly triggers (optional)
follow-up request rules
EVE does not audit. EVE requests and aggregates reports.
